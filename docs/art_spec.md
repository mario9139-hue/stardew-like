# 素材仕様(art_spec)

素材は `assets/art/<カテゴリ>/<名前>.png` に置く。ファイルが無いときは、仮の色付き四角が自動で使われる。
素材の取得はすべて `SpriteProvider.get_texture(id)` 経由(ID は `カテゴリ/名前`)。
タイルサイズ・解像度は `scripts/game_config.gd`(`GameConfig`)だけで決まる。下の寸法は **基準値(TILE_SIZE=16, 320x180)** で書き、
`T` はタイルサイズ(`GameConfig.TILE_SIZE`)を表す。TILE_SIZE を変えたら、素材も `T` に合わせて描き直す。

素材を追加・削除したあとは、ゲームを再起動すると反映される(結果をキャッシュしているため)。

## 共通ルール
- 形式: PNG(透過あり)。拡大縮小はしない(`nearest` フィルタ、ピクセルアート前提)
- 画像の大きさは、下の「推奨サイズ」に **ピクセル等倍** で合わせる(`T=16` なら 16px = 1マス)
- ID と ファイル名は半角英小文字・数字・アンダースコア(例: `growth_powder`)

## カテゴリと命名規則
| カテゴリ | ID / ファイル名 | 推奨サイズ | 内容 |
|---|---|---|---|
| `player` | `player/player_up` `player_down` `player_left` `player_right` | 幅 `T` × 高さ `1.5T`(基準 16x24) | 向き4方向。共通で良いなら `player/player` 1枚でも可(向き別が無いときの代わりに使われる) |
| `tiles` | `tiles/grass` `farmland` `tilled` `tilled_wet` | `T` × `T` | 地面タイル。`tilled_wet` は水やり済み |
| `tiles` | `tiles/house` `shop` `well` `sales_box` | 家 56x40 / 店 48x32 / 井戸 16x16 / 出荷箱 18x18(基準) | マップ上の建物・設備。原点(置く位置)は仮素材と同じ(下表) |
| `crops` | `crops/<作物ID>_stage<N>` | `T` × `T`(背の高い作物は縦に伸ばして良い) | 成長段階 N は **1から**(1=種まき直後、最後=収穫可能)。段階数は CropData の `stage_colors` の数。マスの下端中央に揃えて描かれる |
| `items` | `items/<アイテムID>` | `T` × `T`(ドロップは仮素材 6x6) | アイテムのアイコン。ドロップ品(拾えるもの)にも使われる |
| `monsters` | `monsters/<モンスターID>` | 幅 `T` × 高さ `T`(大型は `1.5T` 以上でも可) | 足元がマスの下半分に揃う |
| `ui` | `ui/<名前>` | 自由 | UI 用(今は未使用。将来のアイコン・枠用) |
| `effects` | `effects/hit_flash` | `T` × `T` | 被弾の白点滅用(モンスターの上に重ねる)。シルエットを白で塗った画像にすると自然 |

## キャラクター(player / monsters)
- 幅は 1マス(`T`)、高さは 1.5マス(`1.5T`)を標準とする(例: `T=16` → 16x24、`T=32` → 32x48)
- **足元基準**: 画像の下端が、キャラクターのマスの下端に揃う。背が高くても当たり判定(1マス)は変わらない
- 向き: `up` / `down` / `left` / `right` の4方向(ファイル名の末尾)
- アニメ(将来): `<名前>_<アクション>_<向き>_<フレーム番号>.png`
  - アクション: `idle` / `walk` / `attack` / `hurt`、フレーム番号は 1 から2桁なし(例: `player/player_walk_down_1.png`)
  - 今は静止画のみ使用。アニメ名の規則だけ先に決めている

## マップ上の建物・設備の原点
画像のどこが「ノードの位置(足元)」になるか。素材を差し替えるときは、仮素材と同じ位置に原点が来るように描く。
| ID | 画像サイズ(基準) | 原点(画像左上から) |
|---|---|---|
| `tiles/house` | 56x40 | (28, 40) 下端中央(玄関の下端) |
| `tiles/shop` | 48x32 | (24, 32) 下端中央 |
| `tiles/well` | 16x16 | (8, 8) 中心 |
| `tiles/sales_box` | 18x18 | (9, 10) |

## 作物の例(カブ、段階が4つ)
`assets/art/crops/turnip_stage1.png` 〜 `turnip_stage4.png`
別名にしたいときは `CropData.sprite_id`(素材名)を指定する。アイテム・モンスターも同様に `ItemData.sprite_id` / `MonsterData.sprite_id`(空なら id を使う)。

## タイルサイズを変えるとき
1. `scripts/game_config.gd` の `TILE_SIZE`、必要なら `BASE_WIDTH` / `BASE_HEIGHT` を書き換える(マップのマス数は自動で決まる)
2. 本素材は新しいタイルサイズに合わせて描き直す(仮素材は自動で追従する)
3. 移動速度・攻撃範囲・拾う距離・UI の文字の大きさなどは px のまま(タイルに連動しない)。必要なら別途調整する
