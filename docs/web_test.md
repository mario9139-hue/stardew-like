# Web 版の確認手順(セーブがブラウザで動くか)

セーブは `user://save.json`(ブラウザでは IndexedDB に保存される)。公開URLを開いて確認する。

## 1. 公開されたことの確認
1. `main` に push → GitHub の Actions タブで「Deploy to GitHub Pages」が緑になるのを待つ
2. 公開URL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)をスマホのブラウザで開く
3. 初回は読み込みが重い。タイトル画面(「はじめから」「つづきから」「終了」)が出れば成功
   - 初回は「つづきから」が「データなし」の無効表示

## 2. セーブ・ロードの確認
1. 「はじめから」で開始し、畑を耕して種をまき、水をやる
2. 家で寝て日を進める(朝6:00に自動セーブされる)。PC なら F8 でデバッグを有効にして F11 でも保存できる
3. ブラウザのタブを閉じる(または再読み込み)
4. もう一度公開URLを開く → 「つづきから」が有効になっている
5. 「つづきから」で、同じ日・同じ畑・同じ所持品・所持金で再開できれば成功

## 3. うまくいかないとき
- 「つづきから」が無効のまま: シークレットモード/サイトデータの自動削除設定だと保存されない。通常モードで試す
- ブラウザの開発者ツール(Console)に `SaveManager:` で始まる警告・エラーが出ていないか確認する
- 書き出し後はリソース名が `xxx.tres.remap` になる。`ItemRegistry` はこれに対応しているが、アイテム・作物が復元されない(「未知の id」警告が出る)場合は、ここを疑う
- セーブを壊したときの復元(`save.json.bak`)は、デスクトップ版で確認する(ブラウザではファイルを直接触れないため)
