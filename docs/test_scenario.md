# 通しテストシナリオ: 夜戦 → 拾得 → 就寝 → 翌朝に畑で使用

デバッグキーは `DebugFlags.DEBUG_ENABLED`(既定 ON)の間だけ動く。F8 で ON/OFF。
数値は `data/balance.tres` に集約(スポーン間隔 8秒 / 同時5体 / ドロップ率 成長の粉50%・品質の欠片40% / 成長の粉 +1日 / 品質売値 x1.5)。

## デバッグキー一覧
| キー | 内容 |
|---|---|
| F1 | 次の日へ |
| F2 | 時間 x40 切替(1x ⇔ 40x) |
| F3 | 向いているマスに成長ボーナス(成長の粉と同じ効果) |
| F4 | 向いているマスに高品質付与 |
| F6 | 自分に10ダメージ |
| F7 | モンスターを1体出す |
| F8 | デバッグ機能全体の ON/OFF |

(F5 の強化素材付与は廃止。素材は夜戦のドロップで集める)

## 準備
1. 新規で開始(1日目 6:00)。ホットバーは 1=クワ 2=じょうろ 3=種 などを選ぶ
2. 昼のうちに、種まき(カブ)と水やりをして、畑に作物を 4〜6マス用意する。武器(木の剣)を持っていること
3. F2 で時間を進めて 21:00 の少し手前まで進める(F2 でもう一度押すと 1x に戻る)

## 手順
1. **夜戦**: 21:00 になると Output に `[MonsterSpawner] 夜のスポーン開始` が出る。8秒ごとにスライムが外周から出る。右クリック(攻撃)で倒す
   - Output: `[Debug] ドロップ growth_powder x1(今夜の合計 N個)`
2. **拾得**: ドロップに近づく(32px)と自動回収。画面に「成長の粉 +1」「品質の欠片 +1」
   - Output: `[Debug] 拾得 ...(今夜の拾得合計 N個)`
3. **就寝**: 家で寝る(または 26:00 / 気絶)。日替わり時に Output へ
   `[Debug] ===== N日目開始 / 昨夜の結果: ドロップ ...(M個) 拾得 ...(M個) =====`
   - 成長の粉・品質の欠片が 合計 2〜4個 が目安(下記シミュレーション参照)
4. **翌朝の畑で使用**: 成長の粉/品質の欠片をホットバーで選び、作物マスを向いてクリック(使用)
   - Output: `[Debug] 強化素材を使用 growth_powder cell=... 成長+1日(次の日替わり)`
   - 同じマスに同じ効果は重複しない(「このマスには成長効果が付いています」)
5. **成長確認**: その日の夜に水やり済みのまま就寝/F1
   - Output: `[Debug] 成長効果 cell=... turnip: 成長 1→3 / 3日(ボーナス+1日)`
   - 通常は +1 のところ +2 進む。未水やりなら「未水やりのため不発」(効果は消える)
6. **品質確認**: 品質の欠片を使った作物を収穫 → インベントリに ★ 付き。売却箱に入れて日替わり
   - Output: `[Debug] 品質★売却 カブ x1: 単価 45→68(x1.50) ...`
7. 夜が来るたび `[Debug] ===== 夜開始(昼の強化素材使用: ...)=====` に、昼に使った個数が出る

## 成功条件
- 1夜で 成長の粉+品質の欠片 が合計 2〜4個 前後(運で ±)
- 使用すると所持数が1減り、翌日の成長が +1日 前倒しされる
- 品質作物の精算額が 1.5倍(端数は四捨五入)
- F8 で OFF にすると F1/F2/F3/F4/F6/F7 と `[Debug]` ログが全部止まる

## バランス確認(シミュレーション結果)
前提: 夜 = 50秒(21:00〜26:00、1x)、プレイヤー移動80px/s、スライム40px/s・撃破は到達後0.8秒、
ドロップ率 0.5 / 0.4、プレイヤーは最寄りの敵を追う想定(4000夜の平均)。

| スポーン間隔 | 出現数/夜 | 撃破数/夜 | 強化素材/夜 | 2〜4個の割合 |
|---|---|---|---|---|
| **8秒(現行)** | 4.6 | 3.8 | **3.4** | 42% |
| 10秒 | 3.1 | 3.1 | 2.8 | 55% |
| 12秒 | 3.1 | 2.3 | 2.0 | 58% |

- 現行値の平均 3.4個は目標(2〜4)内なので、パラメータは変更していない
- 理想的に追い回すプレイヤー前提なので、実際は少し下振れする(体感 2〜3個)
- ばらつきが大きいと感じたら、`spawn_interval_seconds` を 10 にすると平均 2.8個で中央に寄る
- 注意: `min_player_distance=200` はマップ中央付近では満たせず、出現が失敗する夜がある(出現数が 4.6 止まりなのはこのため)。緩めたいときは `balance.tres` の値だけ変える
